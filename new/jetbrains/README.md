# JetBrains IDEs Module

## Useful JetBrains IDE Settings

- Disable checking for IDE updates.
  \
  `File | Settings | Appearance & Behavior | System Settings | Updates`
-  Disable checking for plugin updates.
  \
  `File | Settings | Appearance & Behavior | System Settings | Updates`
- Disable reopening projects on startup.
  \
  `File | Settings | Appearance & Behavior | System Settings`
- Enable auto excluding files ignored by Git from analysis.
  \
  `File | Settings | Version Control | Git`

## Useful Commands

- `(pycharm . &)`
  \
  This shell command launches the IDE from the project directory. It ensures
  the IDE has the correct project environment variables. It also allows closing
  the terminal session without closing the IDE.
